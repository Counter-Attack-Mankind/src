1.从A1到B或从B返回A，刚开始的动作必须是倒车

2.起点为真实/虚拟库位时，出库前缀固定为倒车，不再根据主路径方向自动切成前进；同走廊目标会按目标左右侧预留一段反向倒车空间，再接后续前进段。

3.后续路径策略优先采用共通方法：按库位所在区域、左右侧、目标列位置生成共享倒车尖点和入库接入方式；仅对少数无法覆盖的库位使用特殊表兜底，避免逐个库位硬编码。

4.同走廊且靠近起点两侧的库位（如B3/B4与B5/B6）不单独硬编码，而是采用共通规则：在共享倒车尖点后继续水平倒车一段更长距离，先留出横向转弯空间，再前进/转向接入目标库位。

5.终端倒车入库时，最终车身姿态仍必须等于目标库位的dock_theta；倒车只改变运动方向，不能把终点姿态改成dock_theta+pi，否则会出现180度反向入库。

6.真实库位终端不再自动切换为reverse docking；如果正向入库空间不足，应由前段路径先倒车/前进创造接入空间，再按库位dock_theta前进入库，而不是用倒车终端把操作方向翻掉。

7.A1到B10-B19这类从上方取货点进入下一排货架的路径，问题来自跨走廊首个骨架拐点空间过短以及失败后递归切到终端倒车兜底；现在跨走廊出库也会先水平倒车预留转弯距离，同时真实库位不再使用强制reverse docking兜底，避免生成与库位姿态相反的入库段。

8.进一步固定作业约束：真实库位只能倒车出库、前进入库，terminal_reverse只允许用于非真实端点目标；同时为B10-B19加入row1-debug日志，输出终端模式、出库倒车尖点、骨架点和入库参考线，便于判断路径失败发生在出库骨架、终端接入还是曲线平滑阶段。

9.B10-B19的调试日志显示terminal_reverse已经关闭，失败主要发生在前进入库终端90度转弯空间估算：原来用pre_dock_y判断车道距离，会把可用空间低估并夹到更近车道，导致末端垂直段过短；现在改为以后轴最终停车点估算终端转弯空间，使前进入库段有足够长度容纳回旋曲线。

10.针对REVERSE->FORWARD接缝处的KINK，明确按运动方向而不是车身theta判断合法换向：同走廊若出库转弯空间不足，则倒车退到相邻车道后再以前进反向接回；跨走廊时首个连接通道固定为与出库末端方向匹配的一侧，避免倒车末端运动方向和前进首段同向或成90度。

11.为区分“路径未生成”和“路径生成后被判据筛掉”，path_catalog_debug_node增加validate_paths开关；关闭时除empty_path外直接发布原始generate路径，并新增path_catalog_debug_raw.launch用于默认查看未经过task-style validation筛查的路径。

12.raw模式确认B10-B18均已生成，但粗骨架过于简单：A1出库线与目标入库线近距离平行，导致平滑只能用arc fallback硬接。针对row1上排同走廊目标，改为先在可转出的下侧车道完成倒车出库，再沿左右绕行车道中心线切到上侧入库车道，最后前进入库，避免两条短平行线直接拼接。

13.A1到B10/B12/B14的失败进一步定位为换向尖点运动方向不合法：原逻辑把同走廊上排目标的出库落点强行切到上侧车道，倒车曲线拟合失败后退化成竖直倒车，再接水平前进，形成90度cusp并导致theta从90度跳到180度。现在同走廊上排目标统一先落到下侧车道完成可转出的倒车曲线，并移除失败后切换车道的兜底，保证倒车末端运动方向与前进首段近似相反，车身姿态不再原地空转。

14.B10-B18继续出现curvature_discontinuity，是因为上一步虽然修正了换向尖点，但仍把路径拉到左右绕行线后用0.28m的竖向短段切到另一条车道，回旋曲线空间不足。现在同走廊上排目标改为在目标附近预留一段水平换道距离，并扩大短平行换道识别范围，使第一走廊上下车道间的切换按平滑lane shift处理，而不是绕一大圈后再做两个90度硬拐。

15.针对A1到B11/B13/B15/B17/B19，保留“先倒车转水平、再经第一走廊外侧竖直通道进入第二走廊”的基本逻辑，但竖直过渡通道不再按距离最近选择，而是按目标库位在第二走廊内的终端转弯空间选择离目标更远的外侧通道，先获得足够水平进库距离，再在第二走廊内完成接入。

16.进一步修正B11/B13的右侧过渡通道选择：右侧区域存在内外两条竖直车道，原规则虽然选到了右侧远端，但仍使用靠主货架的right_down内侧线，容易与B18附近货物碰撞；现在row1到row2且目标为下排库位时，远端右侧统一使用right_up外侧线，左侧仍使用left_down外侧线。

17.针对B20/B22/B24/B26/B28与B30/B32/B34/B36/B38，禁用第一走廊到第二走廊过渡时靠货架的内侧竖直线：左侧目标固定使用left_down外侧线，右侧目标固定使用right_up外侧线，避免左右内侧车道与行1/行2货架或货物发生碰撞。

18.出库倒车段与后续前进段的衔接必须是尖点而不是圆弧中途切换模式：现在在prepend_initial_reverse末端显式写出同坐标、同车身姿态的REVERSE点和FORWARD点，保证车辆在该点完成离散换向，车身姿态连续但运动方向反向。
